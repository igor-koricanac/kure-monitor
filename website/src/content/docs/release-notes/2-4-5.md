**Released:** 2026-08-04

Kure Monitor 2.4.5 brings a brand new way to consume AI observability by introducing the official Grafana App plugin, alongside major SEO improvements and documentation restructuring.

### Headline Changes

- **Grafana App Integration**: Kure Monitor now ships with a dedicated Grafana App plugin! Bring the proactive AI troubleshooting chat, failure feed, and AI Advice directly into your existing observability dashboards. See the [Grafana Integration](/integrations/grafana/) guide for setup instructions.
- **Custom Domain & SEO Expansion**: Migrated all official documentation, Helm charts, and plugin metadata to the new custom domain (`https://kuremonitor.com`). Created deep-dive error troubleshooting guides (CrashLoopBackOff, OOMKilled, ImagePullBackOff) to help users debug faster.
- **Documentation Overhaul**: Introduced an "Integrations" section and cleaned up legacy markdown files to keep the Astro Starlight site clean and focused on our four core pillars: AI Advice, Security Scanner, Diagram, and Pod Monitoring.
