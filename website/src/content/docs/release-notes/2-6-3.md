**Released:** 2026-11-23

Kure Monitor 2.6.3 brings High Availability support for multi-replica backend deployments, a full Admin-only Audit Log with real-time WebSocket streaming and SIEM-ready JSON logging, optional LLM reasoning effort & HTTP/HTTPS proxy configuration, and a major visual & navigation overhaul of the Topology Diagram.

### Headline Changes

- **Multi-Replica Backend HA (`backend.replicaCount: 2+`)**: Scale the backend API across multiple pods with zero extra infrastructure. PostgreSQL `LISTEN/NOTIFY` fans out WebSocket events and LLM config reloads across sibling replicas with per-pod `instance_id` deduplication (zero duplicate messages), and advisory locks ensure background cleanup jobs run on only one replica at a time.
- **Admin-Only Audit Log (UI + PostgreSQL + Structured `stdout` JSON)**: Tracks every mutating action across Pods, Mirror Pods, LLM configs, Security Scanner, Exclusions, AI Advice, Notifications, SSO, Auth, Users, and Teams.
  - Strictly restricted to `admin` users (both API endpoints and the **Admin Panel → Audit Log** tab).
  - Live real-time WebSocket streaming to admin sessions, plus search, action filtering, expandable JSON payloads, and **CSV / JSON export**.
  - Configurable retention in days via the Admin UI or Helm (`auditLog.retentionDays`, default `90`).
  - Automatic redaction of API keys, passwords, client secrets, webhook secrets, and proxy credentials.
- **LLM Reasoning Effort & HTTP/HTTPS Proxy URL**: Configure optional `reasoning_effort` (`low`, `medium`, `high`, or model default) and optional `proxy_url` (supports `http://user:pass@proxy:8080`) for outbound LLM requests in air-gapped or corporate proxy environments.
- **Topology Diagram Redesign & Navigation**:
  - Modern resource cards with left color accents, icon badges, and live status indicator dots.
  - Default Horizontal (`LR`) layout with 1-click Horizontal/Vertical toggle and clean orthogonal `smoothstep` edges.
  - **Find node...** search to pan, zoom, and highlight any resource instantly.
  - **Core Only / All Resources** toggle to hide supporting objects (`ReplicaSet`, `ConfigMap`, `Secret`, `Endpoints`, `ServiceAccount`).
  - Interactive **MiniMap**, smart auto-collapse for busy namespaces, and friendly 404/403 messages.

## Helm Configuration

To run multiple backend replicas and configure default audit log retention:

```bash
helm upgrade kure-monitor kure-monitor/kure --version 2.6.3 -n kure-system \
  --set backend.replicaCount=3 \
  --set auditLog.retentionDays=90
```
